# Multi Sender

Multi Sender by Multi Sender.

## Installation

### Windows
1. Download the latest **`.exe`** installer from the [Releases page](https://github.com/digi-bulk-marketing/6839b972c58a2dddbb7bf301/releases/latest).
2. Run the installer and follow the prompts.
3. Launch **Multi Sender** from the Start menu.

## Updates

Download the newest installer from the [Releases page](https://github.com/digi-bulk-marketing/6839b972c58a2dddbb7bf301/releases/latest) and reinstall.
